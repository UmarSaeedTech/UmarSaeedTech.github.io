Touchless Interaction: Real-Time 21-Point Hand Tracking Using MediaPipe

Case Study • Published by Umar Saeed

Human-Computer Interaction (HCI) Vision

This project eliminates traditional physical input peripherals by leveraging real-time computer vision. Utilizing MediaPipe's 3D hand landmark framework paired with PyAutoGUI, hand motion vectors are smoothed and mapped to native OS mouse movements and gesture clicks.
