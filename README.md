## 📌 Overview

This repository contains the source code, custom layout styling, and technical case studies for my professional portfolio as an **AI Researcher & Computer Vision Developer**.

### Core Technical Focus Areas
- **Real-Time Computer Vision:** Custom YOLO architectures (v8, v11, v12) for object detection, threat surveillance, and PPE compliance.
- **Human-Computer Interaction (HCI):** Real-time 21-point hand tracking and gesture-driven control interfaces via MediaPipe and OpenCV.
- **Healthcare AI Infrastructure:** Architectural design and donor-matching frameworks for emergency blood dispatch systems (BloodLink).
